# ShopSense AI
## Online Shopping Purchase Intention Prediction

ShopSense AI is a machine learning web application that predicts whether an online visitor is likely to make a purchase.

### Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Machine Learning: Logistic Regression

### Project Files
- `app.py` - Streamlit web application
- `purchase_model.pkl` - Trained ML model
- `feature_names.pkl` - Model feature names
- `requirements.txt` - Required Python libraries

### Run the Application
1. Install Python.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Run:
   `streamlit run app.py`

### Dataset
UCI Machine Learning Repository - Online Shoppers Purchasing Intention Dataset.

### Disclaimer
Predictions are estimates from the trained model and are not guaranteed outcomes.
